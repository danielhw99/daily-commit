# 2. Add Two Numbers

## 문제 정보

- 링크: [LeetCode 문제](https://leetcode.com/problems/add-two-numbers/)
- 대표 유형: linked-list
- 관련 유형: math, simulation
- 난이도: Medium
- 풀이 날짜: 2026-09-26
- 언어: Python
- 상태: 풀이 완료·제출 미확인

## 문제 설명

음이 아닌 두 정수가 연결 리스트로 주어진다. 각 노드는 한 자릿수를 담고 있으며 일의 자리부터 저장된다. 두 수를 더한 결과도 같은 순서의 연결 리스트로 반환한다.

- 각 리스트의 노드 수는 1~100개이며 노드 값은 0~9이다.
- 숫자 0 자체를 제외하면 선행 0은 없다.
- 예: `[2,4,3] + [5,6,4] → [7,0,8]`은 `342 + 465 = 807`을 뜻한다.

## 접근 과정

1. 두 리스트를 함께 순회하며 현재 값을 읽는 방법으로 시작했다.
2. 길이가 다르면 한쪽 노드가 먼저 없어지므로, 없는 쪽 자릿값은 0으로 처리했다. 다음 노드로 이동할 때도 None 여부를 확인했다.
3. 역순으로 저장되어 있으므로 뒤에서 읽을 필요 없이 머리부터 덧셈을 진행했다.
4. 자릿수 합에 이전 carry를 더하고, `// 10`으로 올림을, `% 10`으로 저장할 숫자를 구했다. `합 - 10`은 합이 10보다 작을 때 사용할 수 없으며 `/ 10`은 나머지를 구하지 않는다.
5. 더미 노드와 current를 사용해 결과를 연결했다. 기존 객체인 `answerNode(value)`를 호출하면 오류가 나므로 `ListNode(value)`로 새 노드를 생성했다.
6. 두 리스트가 끝나도 올림이 남을 수 있어 반복 조건을 `l1 or l2 or carry`로 수정했다.

## 풀이 해설

[풀이 코드](solution.py)

각 반복에서 두 자릿값과 이전 올림을 더한다. 합의 일의 자리를 새 노드로 연결하고 십의 자리를 다음 carry로 넘긴다. current는 결과의 마지막 노드를 가리키며, answerNode는 더미 노드 위치에 남는다. 마지막에 answerNode.next를 반환해 더미를 제외한다.

각 반복 시작 시 이미 만든 노드들은 처리한 하위 자릿수의 정확한 합이며, carry는 다음 자리로 전달할 올림이다. 몫과 나머지로 이를 유지하며 모든 자리와 마지막 올림까지 처리하므로 전체 합이 완성된다. 입력이 끝난 뒤 carry만 남으면 그 값을 마지막 노드에 넣고 carry가 0이 되어 종료한다.

## 복잡도

- 변수 정의: n과 m은 각각 두 입력 리스트의 노드 수이다.
- 시간 복잡도: O(max(n, m)). 각 자릿수를 한 번 처리하고 마지막 올림에 최대 한 번 추가 반복한다.
- 공간 복잡도: 결과 리스트를 포함하면 O(max(n, m)), 결과를 제외한 보조 공간은 O(1)이다.

## 검증과 주의점

- 로컬 검증: 테스트 실행을 시도했으나 Python 실행 파일에 접근할 수 없고 py 런처도 없어 실행하지 못했다. LeetCode 제출 결과는 미확인이다.
- 확인할 사례: 일반 덧셈, 0 + 0, 서로 다른 길이, 마지막 올림, 연속 올림, 최대 길이 100자리.
- ListNode는 LeetCode에서 제공한다. 로컬 실행에는 동일한 val/next 구조의 노드 클래스가 필요하다.
- `sum`이라는 변수명은 Python 내장 함수 이름을 가린다. 현재 코드의 동작에는 영향이 없으며, 가독성을 위해 추후 `total` 같은 이름을 사용할 수 있다.

## 복습

- 핵심 아이디어: 연결 리스트 순회와 자릿수 덧셈을 결합하고 carry를 다음 반복으로 전달한다.
- 더미 노드를 사용하면 첫 결과 노드도 나머지 노드와 같은 방식으로 연결할 수 있다.
- 입력을 모두 읽었더라도 처리할 상태가 남아 있으면 반복을 계속해야 한다.
